# 校招投递助手

一个帮你填校招网申表单的 Chrome / Edge 浏览器插件。

用任意 AI（ChatGPT、Claude、Kimi、豆包、DeepSeek 等）把简历整理成一份资料，导入插件。之后打开网申页面，插件会识别表单，把基本信息、教育经历、实习、项目、校园经历、奖项、语言能力等自动填进去。多条经历的表单会自动点「添加」，下拉框、日期选择器也会尽量选好。

- **资料只存在你自己的浏览器里**，插件没有服务器，不会上传你的资料。
- **只填表，不提交**。插件不会点「保存」「暂存」「下一步」「提交」，最后一步由你自己检查、确认。
- **默认不覆盖**你已经填过的内容。

> 这是个人业余项目，在 Moka、飞书招聘、Element UI / Ant Design 类表单和若干企业自建网申系统上测试过。各家网站结构差异很大，**提交前请一定逐项检查**。

## 安装

1. 下载本仓库：点右上角 **Code → Download ZIP** 后解压，或 `git clone`。
2. 打开 `chrome://extensions`（Edge 是 `edge://extensions`），打开右上角的 **开发者模式**。
3. 点 **加载已解压的扩展程序**，选择解压后的文件夹（里面有 `manifest.json` 的那一层）。
4. 建议把插件图标固定到工具栏。

## 导入资料：一键用 AI 解析简历

1. 点插件图标 → **资料管理**（第一次用会直接提示你去导入）。
2. 点 **复制提示词**。
3. 打开任意 AI 对话，粘贴提示词，然后把简历全文贴在最后，或直接上传简历文件。简历上没有的信息，比如籍贯、民族、政治面貌、期望城市，可以一起写给 AI。
4. 把 AI 返回的 JSON 粘贴回「资料管理」页，点 **检查并保存**。带着 ```json 代码块一起粘贴也可以。
5. 页面会显示读到了几段教育、几个项目，并提示缺了哪些常用字段。你可以直接在框里修改，再保存。

提示词全文见 [AI解析提示词.md](AI解析提示词.md)。它要求 AI：只用你给的信息，没有的留空，不编造；不写身份证、护照等证件号；经历原文不缩短。

想先看看效果，可以在「资料管理」页点 **载入示例资料**。示例里的人物是虚构的，示例文件是 [profile.example.json](profile.example.json)。

**换电脑或重装插件前**，在「资料管理」页点 **下载备份**，之后用 **从 .json 文件导入** 恢复。

## 使用

- **自动填写**：打开网申表单页面，插件会自动填一次。很多网申页面是逐步加载的，所以 3 秒后会再补一次。右下角的提示会告诉你填了几个字段、哪些没填上。
- **手动填写**：点插件图标 → **立即重新扫描并填充当前页**。
- **只填某一项**：弹窗下半部分按类别列出了你的每段经历。点「填」只填这一项，点「复制」可以手动粘贴。
- **投递方向**：如果你在资料里定义了方向（例如数据分析、产品经理），并给项目标了方向，弹窗里可以切换方向，只填对应的项目。没定义就填全部项目。
- **覆盖开关**：默认关闭，只填空白的框。打开后，已有内容的框也会被资料覆盖。

## 它不会做什么

- 不会点「保存」「提交」「下一步」或「删除」。
- 不会填身份证号、护照号这类证件号，请自己填。
- 下拉选项里没有和你资料对得上的项，就不选，并在提示里告诉你，不会随便选一个相近的。
- 不会替你登录，也不会勾选个人声明、隐私协议。

## 已知限制

- 实习经历目前只支持一段（资料里的 `internship`）。
- 个别网站的日期控件或自定义下拉可能选不上，这些会列在“没填上”的提示里，请手动补。
- 插件需要在所有网站上运行识别脚本，安装时 Chrome 会提示“读取和更改你访问的所有网站上的数据”。脚本只在看起来像表单的页面（至少 4 个输入框）才会动作，也不会联网。不放心的话，可以在弹窗里关掉自动填充，只在需要时手动点。

## 隐私

- 资料保存在浏览器的 `chrome.storage.local` 里，只有这个插件能读。
- 插件没有任何网络请求。用 AI 解析简历时，简历会发给你选择的 AI 服务，请按你自己的隐私偏好选择，也可以先删掉敏感内容。
- `.gitignore` 默认忽略 `profile.json`、`my-profile*.json`，避免你 fork 后误把自己的资料提交上去。

## 开发与测试

```
python3 tests/serve.py          # 端口被占用可以换：python3 tests/serve.py 8766
```

然后用浏览器打开：

- `http://127.0.0.1:8765/tests/`：回归测试。用模拟的各家网申表单跑一遍填写引擎，目前 135 项检查。
- `http://127.0.0.1:8765/tests/ext-smoke.html`：插件流程冒烟测试，覆盖导入资料、解析 AI 回复、填写。

### 文件说明

| 文件 | 作用 |
|---|---|
| `fill-engine.js` | 填写引擎：识别控件和标签、划分分区、把经历对到行上、填写和读回验证 |
| `content.js` | 页面脚本：自动填写、接收弹窗的填写请求 |
| `popup.html` / `popup.js` | 插件弹窗 |
| `setup.html` / `setup.js` | 资料管理页（导入、编辑、备份） |
| `profile-store.js` | 资料的读写、解析和检查 |
| `profile-view.js` | 按投递方向挑项目、单项填写 |
| `prompt.js` | AI 解析提示词（改完运行 `node tools/make-prompt-md.js` 更新 `AI解析提示词.md`） |
| `tests/` | 回归测试、模拟表单、虚构的测试资料 |

适配新网站时，可以在网申页面的控制台运行 `window.postMessage({ type: "AYA_DIAG" }, "*")`。它会打印每个输入框被识别成了什么字段，输出里只有标签，不包含个人资料。

欢迎提 Issue 或 PR。修 bug 时请在 `tests/cases.js` 里加一个能复现问题的用例。
